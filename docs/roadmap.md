# 项目路线图

掠影的核心目标是构建在流畅度、准确率与资源控制上均处于领先地位的现代拼音输入法。核心保持极简与纯粹，所有高级定制与外延功能均通过标准扩展接入。

## 架构演进现状

### 核心引擎与模型
- [x] **音节图与分词**：基于词图 Viterbi 的全拼、简拼与整句实时解码。
- [x] **纠错与容错**：内置自动模糊音与手误容错机制，末音节自适应补全。
- [x] **词库与模型**：白霜词典 mmap 内存映射（`main.pyd`）、N-gram 语法模型、4M 每键同步重排与 25M 停顿异步重排。
- [x] **自学习系统**：选词自学习提频、同键负分抑制、自动造词、上下文与按应用隔离学习。

### 交互与渲染
- [x] **双层渲染管线**：Skia GPU（DirectComposition + D3D12）优先，CPU 分层窗口平滑自动兜底。
- [x] **界面呈现**：横排/竖排自适应排版、三档字号、六种主题预设、多屏高 DPI 支持及屏幕边缘避让。
- [x] **无障碍与动效**：原生支持 Windows 高对比度模式，在系统开启「减少动态效果」时自动平抑动效。
- [x] **图形设置中心**：分类导航、实时候选预览、内置原生编辑框与全量 UI Automation 读屏支持。

### 扩展生态与能力开放
- [x] **编译期方案扩展**：标准全拼与主流双拼（小鹤、自然码、微软、搜狗）。
- [x] **编译期候选模块**：五笔辅助码单字过滤、自定义短语、下一词智能联想、特殊符号与快捷模式（`v` / `u` 模式）。
- [x] **运行期脚本沙箱**：基于 QuickJS 的独立工作线程沙箱，支持外观动态装饰、命令注册与声明式设置。
- [x] **服务原语与官方扩展**：开放截图、OCR、剪贴板、私有存储与系统通知等服务原语，提供官方 `shot-ocr` 扩展。
- [x] **外部联动**：提供 CLI 桥接命令（`lueying ext run`），原生支持 PowerToys 等启动器联动唤起。

### 工程与安全
- [x] **网络边界隔离**：常驻服务端坚决不引入网络库；更新与扩展代理独立运行，扩展外联严格受白名单限制。
- [x] **端到端门禁**：覆盖真实 TSF 宿主、32 位兼容、安装卸载冒烟及共享语料库准确率基准。
- [x] **指标基线约束**：严格控制二进制体积（≤ 80 MiB）、常驻内存（≤ 128 MB）与按键延迟（p95 ≤ 60ms）。

## 后续演进规划

### 1. 核心排序与解码演进
- 持续调优首选命中率与复杂长句输入准确度。
- 优化长周期生僻字召回与高频生词冷启动学习效率。
- 词库与重排延迟长期趋势的自动化监控。

### 2. 分发与平台兼容拓展
- 推进 Windows ARM64X 原生 TSF 支持。
- 探索离线词典与重排模型的增量差分更新机制。

### 3. 扩展生态深化
- 支持用户图形化自定义双拼键位映射。
- 扩充系统级快捷动作，完善剪贴板历史与多模型离线 OCR 适配。

## 扩展设计准则

1. **核心纯粹**：核心引擎只专注汉字全拼切分、候选生成与自学习，不内置具体业务功能。
2. **零空闲成本**：扩展未激活时不占用线程与额外内存，按键热路径执行预算控制在 1～2ms 内。
3. **平台原语抽象**：核心仅提供平台级安全原语（如截图、通知、剪贴板），具体业务逻辑交由扩展自由编排。
4. **安全沙箱隔离**：系统密码框与隐私字段自动挂起扩展层；所有敏感权限遵循声明式授权与调用审计。
