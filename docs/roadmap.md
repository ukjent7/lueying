# 掠影路线图

掠影（slug `lueying`）是 Windows 11 的中文拼音输入法。当前阶段只做 Windows 基础输入体验：解码、候选排序、模糊音、纠错、长期学习、延迟、稳定性、候选窗与安装，目标是领先微信输入法、水杉、青简、清风四个对标产品。

## 范围

- 输入方案：全拼与简拼。暂不做双拼、五笔、形码或辅助码。
- 设置：开箱即用，只保留使用习惯类调优（候选数、中文标点、Shift 切中英、模糊音总开关）。新增设置项必须证明是多数用户需要的习惯调优。
- 语言模型：默认使用 4M 同步重排 + 25M 停顿重排。万象 400MB 级模型效果好但体积过大，留作可选包；项目还要为后续随包 OCR 模型预留约 200MB 级空间。
- 平台：当前只做 Windows 11。macOS（ARM）作为后续平台，暂不启动；不投入 Linux、Android、iOS。
- 形态：非商业项目，不依赖网络服务，不做日志上传、云端同步、自动更新。`lueying-server` 只是本机常驻进程。

## 后续能力（未排期）

- 剪贴板：替代 Win+V。
- 截图：对标微信桌面版的截图流程，图片处理参考 Pi。
- OCR：对标 LunaTranslator。
- macOS 版：GUI 美学与动效参考 macOS 26–27 的 Liquid Glass，但以输入法延迟和资源占用为硬约束；笔记见 `docs/macos-liquid-glass.md`。
