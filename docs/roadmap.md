# 路线

## 已完成

- **输入**：全拼、简拼、双拼（小鹤、自然码、微软、搜狗）、整句词图解码、模糊音、五笔辅助码、下一词联想。
- **学习**：选词提频、同键负分、自动造词、按应用隔离。
- **重排**：8M 每键同步重排、25M 停顿异步重排，模型缺失时自动降级。
- **界面**：Direct2D 候选窗、横竖排、三档字号、主题预设、多屏高 DPI、高对比度与减少动效。
- **设置与配置**：设置窗（UI Automation）、备份、词库导入、WebDAV 云同步。
- **扩展**：Wasm 扩展与原生扩展、候选窗状态事件、官方扩展（截图识别、剪贴板历史、语音输入）。
- **平台**：Windows。
