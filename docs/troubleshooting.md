# 故障排查

本文档列出常见使用问题、定位方法、日志记录规则与问题反馈规范。

## 常见问题处理

### 1. 安装后输入法列表中未显示「掠影」
- **架构确认**：确认系统为 64 位 Windows 10（1809+）或 Windows 11；掠影当前不支持 ARM64 宿主。
- **列表检查**：按快捷键 `Win + Space` 查看系统输入法切换列表。
- **修复注册**：若仍未出现，请重新运行安装程序，以管理员权限执行「修复安装」。
- **升级锁定**：升级后若宿主仍占用旧 DLL，新版本 DLL 会按文件名并存，重启宿主应用或注销登录即可完成彻底切换。

### 2. 候选窗口不出现或打字无响应
掠影输入法由常驻进程 `lueying-server.exe` 处理击键与候选生成。若服务异常退出或挂起：
1. 打开 Windows 任务管理器，在进程列表中找到并结束 `lueying-server.exe`。
2. 重新聚焦任意可编辑文本框并敲击任意按键，TSF 驱动壳将自动拉起全新服务实例。

### 3. 候选词质量下降或仅出简短单字
通常是核心离线资源缺失导致的引擎降级：
- 确认安装目录（默认 `%ProgramFiles%\lueying\`）中存在以下核心资产：
  - `main.pyd`：主词典二进制内存映射文件。
  - `main.gram`：语法搭配模型。
  - `rerank-4m.safetensors`：每键实时同步重排权重。
- 若上述文件损坏或缺失，引擎会自动退回内置微型词典；重新安装可修复核心资源。
- 进阶的 `rerank-25m.safetensors`（停顿重排）与 PP-OCR 模型属于按需下载组件，请在「掠影设置 → 扩展 → 官方扩展」中重新下载。

## 日志与诊断排查

### 服务端日志
- 常驻服务启动、配置加载、异常降级及执行超时（单请求耗时 > 100ms 的慢请求）均记录在：
  ```
  %LOCALAPPDATA%\lueying\logs\server.log
  ```
- 日志文件大小超过 1 MB 时自动滚动归档为 `server.log.1`（仅保留一份历史记录）。

### TSF 宿主轨迹跟踪
TSF 薄壳按键与文本编辑会话日志默认仅输出至 Windows 调试器。若需排查特定应用的键盘交互异常，可设置用户环境变量启用本地文件记录：

```powershell
[Environment]::SetEnvironmentVariable('LUEYING_TSF_LOG', "$env:TEMP\lueying-tsf.log", 'User')
```

重启目标应用后，相关按键与编辑交互轨迹将写入指定文件。排查结束后将该环境变量删除即可。

> [!NOTE]
> TSF 跟踪日志仅包含按键消息流与编辑会话状态代码，绝不收集用户的输入正文内容。

### UIA 上下文跟踪
若需排查左邻上下文回退提取流程，可设置系统环境变量 `LUEYING_DEBUG_UIA=1`，详情将输出至系统调试流。

## 问题反馈规范

若遇到未涵盖的异常，欢迎在 GitHub 提交 Issue。为便于快速定位，建议随工单提供以下信息：

1. **环境信息**：Windows 详细版本号及系统架构。
2. **应用上下文**：发生异常的应用名称（如 Word、VSCode、游戏客户端），以及是否属于自绘窗口。
3. **软件版本**：掠影具体构建版本号（在「掠影设置 → 关于」查看）。
4. **诊断报告**：在「掠影设置 → 关于」中点击「导出诊断信息」，将生成的文本附件粘贴至工单中（敏感信息已脱敏）。
