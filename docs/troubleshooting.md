# 排障

## 装了但没有「掠影」

- 确认是 x64 系统;安装包会给 32 位宿主另装一份 `lueying_tsf32-<版本>.dll`。
- 按 `Win + 空格` 看输入法列表;没有的话重新运行安装包修复安装。
- 升级后宿主仍加载着旧 DLL 时,新版本按文件名并存,不会互相覆盖;注销或重启后彻底切换。

## 候选不出现或输入无响应

输入法由常驻服务 `lueying-server.exe` 处理按键。服务异常时:

1. 在任务管理器结束 `lueying-server.exe`。
2. 重新按任意键或重新聚焦输入框,TSF 会重新拉起服务。

服务在用户会话里按需启动,不需要管理员权限。

## 候选质量明显下降

多半是词典或模型没有装上。程序目录里应有:

| 文件 | 作用 |
|---|---|
| `main.pyd` | 主词典(二进制) |
| `main.gram` | 语法模型 |
| `rerank-4m.safetensors` | 每键同步重排 |
| `rerank-25m.safetensors` | 停顿重排 |

缺任何一个都能启动,但会退回内置小词库或关闭对应模型。重新安装可以补齐。

## 记录日志

常驻服务的启动、降级与请求处理失败会写进 `%LOCALAPPDATA%\lueying\logs\server.log`。
文件超过 1 MB 时,下次启动会把它滚动成 `server.log.1`(只保留一份)。调用方显式接管
标准输出时(例如自动化测试),输出留在调用方,不写这个文件。

TSF 侧的按键与编辑轨迹默认只写调试器输出。需要留档时,设置用户环境变量后重启目标程序:

```powershell
[Environment]::SetEnvironmentVariable('LUEYING_TSF_LOG', "$env:TEMP\lueying-tsf.log", 'User')
```

日志只包含按键路径、编辑会话结果与失败原因,不含上屏文本以外的输入内容;排障后把变量删掉即可。

UIA 文本回退的取文过程可以另开 `LUEYING_DEBUG_UIA=1` 输出到调试器。

## 报告问题

请附上:

- Windows 版本与是否 x64。
- 「掠影设置 → 检查更新」显示的版本。
- 出问题的应用名称,以及是自带绘制候选的应用还是普通编辑框。
- 开日志后的相关片段。
