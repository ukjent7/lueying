# 使用

## 基本输入

直接打全拼,空格上屏首选。整句按词图解码,长句不需要逐词选字。

| 操作 | 按键 |
|---|---|
| 上屏首选 | `空格` |
| 选择候选 | `1`–`9` |
| 翻页 | `-` / `=`、`PageUp` / `PageDown` |
| 上下移动高亮 | `↑` / `↓` |
| 原样上屏拼音 | `Enter` |
| 取消本次输入 | `Esc` |
| 删除光标前一个音节 | `Ctrl + Backspace` |
| 按音节移动光标 | `Ctrl + ← / →` |
| 切中英文 | 单击 `Shift`(按住 `Shift` 仍输入大写) |
| 忘掉高亮候选 | `Shift + Delete` |

简拼与混输都可以直接打:`nh` 出「你好」,`woxihuan` 也能按全拼解码。模糊音默认自动召回,精确命中的候选排在模糊候选之前。

## 标点与符号

中文标点默认开启:`,` `.` `;` `:` `?` `!` 按中文习惯输出,数字后的 `.` 保持半角,方便输入小数与 IP。想把某个符号换成别的输出(比如 `,` 上屏「、」),在设置「词库 → 自定义标点」里编辑 `punct.txt`,一行一条 `键=输出`。

单个应用想关中文标点或不留学习记录,在「词库 → 按应用配置」里编辑 `apps.toml`。

- `v` 模式:符号、数字读法、金额、日期与算式,如 `vjt` 取箭头、`v123` 读数字。
- `u` 模式:按码点问字,`u4e2d` 或 `u+4e2d` 都得到「中」。
- 邮箱与网址:在用户名后接 `@` 或输入 `https://` 时,字母、数字、`.`、`/`、`-` 都并入组合,整串一次上屏。

## 扩展

默认使用全拼。设置里可以切换双拼、打开辅助码、开关下一词联想、编辑自定义短语:

- [双拼](extensions/shuangpin.md):小鹤、自然码、微软、搜狗、全拼。
- [自定义短语](extensions/custom-phrases.md):`编码<TAB>候选` 一行一条。
- [辅助码](extensions/auxiliary-code.md):拼音后按 `` ` `` 再打 1–2 位五笔码。
- [下一词联想](extensions/prediction.md):按本机上屏词序补全。
- [用户效果](effects.md):写一段 SkSL 装饰候选窗的面板底、选中块与右键菜单。

## 候选窗

候选窗跟随光标,支持多屏与每屏 DPI;靠近屏幕边缘时自动翻转或平移;全屏应用、UWP 与游戏等自绘宿主会让位给宿主自己的候选绘制。高对比度和「减少动态效果」会改变配色与动画。

右键候选可以置顶该词或跳过它;置顶优先于重排与快捷候选。
