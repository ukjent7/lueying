# 使用指南

本文档介绍掠影输入法的日常交互操作、快捷键映射、符号输入模式及候选词管理。

## 基础操作按键

掠影默认支持全拼输入与长句智能分词解码，首选用空格即可直接上屏。

| 操作 | 默认快捷键 | 说明 |
|---|---|---|
| **上屏首选** | `Space`（空格） | 确认当前首选候选词上屏 |
| **选择数字候选** | `1` ～ `9` | 直接上屏对应序号的候选词 |
| **候选翻页** | `-` / `=` 或 `PageUp` / `PageDown` | 向前或向后翻页 |
| **高亮项选择** | `↑` / `↓` | 循环上下切换候选高亮项 |
| **原样上屏字母** | `Enter` | 丢弃解码结果，直接提交原始输入英文字符 |
| **清除当前输入** | `Esc` | 清空当前的拼音组合缓冲区 |
| **按音节删除** | `Ctrl + Backspace` | 回退删除光标前完整的一个音节 |
| **按音节移动光标** | `Ctrl + ←` / `Ctrl + →` | 在已切分的拼音串间左右步进移动 |
| **中/英文切换** | 单击 `Shift` | 切换中英输入状态（长按或组合键仍作为修饰键） |
| **删除特定自造词** | `Shift + Delete` | 高亮某候选时触发，将其从用户词库中移除 |

## 特殊模式与符号输入

### 标点符号映射
- **中文标点**：默认处于开启状态。逗号、句号、分号等按中文全角标点输出；紧随数字后的 `.` 自动保持半角格式，避免影响 IP 地址或浮点数值输入。
- **自定义标点**：可在设置中直接编辑 `%APPDATA%\lueying\punct.txt`，按 `键=输出` 建立自定义映射规则。

### 快捷引导模式
- **`v` 模式（符号与工具）**：
  - 符号与标点：如输入 `vjt` 输出常用箭头符号。
  - 数字读法与金额：如输入 `v123` 输出大写中文金额或数字文本。
  - 日期与简易计算：如通过简短代码快速生成当前日期、时间或计算结果。
- **`u` 模式（Unicode 编码查字）**：
  - 支持通过十六进制 Unicode 码点问字，例如输入 `u4e2d` 或 `u+4e2d` 直接召回「中」。
- **网址与邮箱识别**：
  - 当输入检测到以 `http://`、`https://` 或字母后接 `@` 时，输入法自动保持半角直通并整体上屏。

## 候选窗口交互

- **自适应光标跟随**：窗口紧随文本编辑框光标，支持高 DPI 逐显示器自动缩放；当靠近屏幕边缘时自动翻转或平移贴靠。
- **自绘应用让位**：全屏游戏或具备自定义候选窗口的应用中，掠影自动让位以避免画面重叠。
- **鼠标交互与右键菜单**：
  - 单击候选词即可完成上屏。
  - 右键点击候选词可弹出上下文菜单，支持「置顶该词」或「忽略此词」。置顶项优先于模型重排。
- **无障碍保障**：系统开启「高对比度」或「减少动态效果」时，候选窗自动停用个性化色彩与动效，切换为高无障碍对比模式。

- **[五笔辅助码](extensions/auxiliary-code.md)**：支持在拼音后按 `` ` `` 键追加 1～2 位五笔码缩小候选范围。
- **[自定义短语](extensions/custom-phrases.md)**：通过纯文本维护专属缩写和快捷短语。
- **[下一词联想](extensions/prediction.md)**：依据本地写作词序自适应给出后续词建议。
- **[界面皮肤与效果](skin.md)**：支持通过 `skin.toml` 或 SkSL 着色器深度定制候选窗外观。
