# 使用

## 基本按键

| 按键 | 作用 |
|---|---|
| 字母 | 输入拼音，支持全拼、简拼与双拼（见[设置](settings.md)） |
| `Space` | 上屏首选 |
| `1`–`9` | 上屏当前页对应序号的候选 |
| `↑` / `↓` | 移动高亮 |
| `-` / `=`、`PageUp` / `PageDown` | 翻页；没有候选时 `-`、`=` 照常输入标点 |
| `Enter` | 上屏拼音字母原文 |
| `Esc` | 清空当前拼音 |
| `Backspace` | 删除一个字符 |
| `Ctrl + Backspace` | 按音节删除 |
| `Ctrl + ←` / `Ctrl + →` | 按音节移动光标 |
| 单击 `Shift` | 切换中英文（设置中可关闭） |
| `Shift + Delete` | 从用户词库移除高亮的候选，用于删掉误学的词 |

## 快捷输入

以下触发串直接给出候选。选中后上屏，不写入用户词库。

| 触发 | 内容 | 例子 |
|---|---|---|
| `rq` | 日期 | |
| `sj` | 时间 | |
| `xq` | 星期 | |
| `v` | 符号、数字读法与金额、算式 | `vjt` 得到箭头符号 |
| `u` | Unicode 字符 | `u4e2d` 或 `u+4e2d` 得到「中」 |

## 候选窗

- 候选窗跟随光标，靠近屏幕边缘时自动翻转或贴边。
- 鼠标单击候选即可上屏，也可用鼠标翻页。
- 系统开启「减少动态效果」时关闭动画；开启「高对比度」时使用系统配色，并忽略 `skin.toml`。

## 官方扩展热键

安装并同意官方扩展后可用（见[扩展](extensions/README.md)）：

| 热键 | 功能 |
|---|---|
| `Win + Shift + V` | 剪贴板历史：面板列出最近 60 条，选中后粘贴 |
| `Ctrl + Alt + V` | 离线语音输入：录音后经本地 SenseVoice 识别并上屏 |
| `Ctrl + Alt + O` | 截图识别（OCR） |

语音与截图识别需要先在「设置 → 扩展」中安装对应的官方组件。热键可在 `config.toml` 的 `bindings` 中修改。
