# 安装与卸载

## 系统要求

- Windows 10(1809 及以上)或 Windows 11,x64。
- 不支持 ARM64:原生 ARM64 宿主只能加载 ARM64X 的 TSF DLL,目前没有这样的构建,安装包会直接拒绝。

## 安装

1. 运行 `lueying-<版本>-setup.exe`。
2. 安装程序需要管理员权限:它把程序装到 `%ProgramFiles%\lueying`,并注册 64 位与 32 位 TSF。
3. 安装末尾会以当前用户身份完成输入法注册、开机自启和旧 DLL 清理;这一步不会要求再次提权。

升级安装同一程序即可。配置与学习记录在用户目录,不会被覆盖;TSF DLL 的文件名带版本号,升级时不会被宿主里仍加载的旧 DLL 锁住。

## 启用

安装后按 `Win + 空格`,在输入法列表里选择「掠影」。任务栏语言栏也会出现「中/英」指示。

## 卸载

在「设置 → 应用」或开始菜单的「卸载掠影」中卸载。卸载会停掉常驻服务、注销 TSF,并清除当前用户的输入法注册与自启动项。

## 文件位置

| 内容 | 位置 |
|---|---|
| 程序与词典 | `%ProgramFiles%\lueying` |
| 配置 | `%APPDATA%\lueying\config.ini` |
| 自定义短语 | `%APPDATA%\lueying\phrases.txt` |
| 用户词库 | `%LOCALAPPDATA%\lueying\user.tsv` |

词典与模型都是可选数据:缺失或损坏时程序仍能启动,主词典退回内置小词库,语法模型与神经重排自动关闭,只是候选质量下降。

## 隐私

输入法不联网,不上传按键、候选或上屏文本,也没有遥测。只有「检查更新」会访问 GitHub Releases,且由用户手动点击触发。

学习记录只写本机的用户词库;密码框、私密输入范围与安全桌面不采集文本,也不学习。
