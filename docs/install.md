# 安装与卸载

本文档说明掠影输入法的安装环境要求、安装与卸载流程、文件存储位置及隐私保护规范。

## 系统要求

- **操作系统**：Windows 10（1809 及以上版本）或 Windows 11。
- **架构支持**：x64（64 位）。
- **ARM64 约束**：原生 ARM64 宿主需要 ARM64X 规格的 TSF DLL，当前构建版本暂不支持并在安装阶段予以提示。

## 安装步骤

1. 前往发布页面下载最新版安装程序 `lueying-<版本>-setup.exe`。
2. 运行安装程序（需管理员权限），程序将默认安装至 `%ProgramFiles%\lueying` 并注册 64 位与 32 位 TSF 文本服务。
3. 安装向导结束时以当前用户权限完成输入法状态注册与开机自启配置，无需二次提权。

### 升级说明

直接运行新版安装程序即可。TSF DLL 具备版本化隔离机制，升级过程中不会被正在运行的宿主进程锁定，用户配置文件与词库记录完整保留。

## 启用输入法

安装完成后：
1. 使用快捷键 `Win + Space`（或在任务栏语言指示器中）选择 **掠影**。
2. 切换后状态栏将出现「中/英」状态指示。

## 卸载

在 Windows「设置 → 应用 → 已安装的应用」或开始菜单中选择「卸载掠影」：
- 卸载程序将停止常驻服务、注销 32/64 位 TSF 注册并移除开机自启。
- 被占用的旧 DLL 文件将在系统下次重启后彻底清除。

## 数据目录速查

| 数据类型 | 存储路径 | 说明 |
|---|---|---|
| 程序与内置词典 | `%ProgramFiles%\lueying\` | 核心二进制文件、mmap 二进制词库 |
| 用户主配置 | `%APPDATA%\lueying\config.toml` | 输入方案、界面布局与主题设置 |
| 自定义短语与标点 | `%APPDATA%\lueying\phrases.txt`、`punct.txt` | 用户自定义编码与符号映射 |
| 按需模型资产 | `%APPDATA%\lueying\models\` | 25M 重排模型与 PP-OCR 离线权重 |
| 用户词库数据 | `%LOCALAPPDATA%\lueying\user.tsv` | 本地自学习、词频统计与置顶词 |
| 运行日志 | `%LOCALAPPDATA%\lueying\logs\` | 服务端运行日志与审计日志 |

> [!NOTE]
> 词典与模型具备降级容错能力：主词典损坏或缺失时将自动回退至内置微型词典，模型未安装时引擎降级为词频基础排序。

## 隐私与安全

- **纯本地运算**：核心输入法不具备网络上传模块，绝不上报按键流、候选词、上屏文本或用户词库。
- **隐私输入隔离**：系统密码框、私密字段（如凭据管理）与安全桌面下，输入法自动直通并停用学习与候选生成。
- **可选网络交互**：仅在用户于设置页主动点击「检查更新」时访问 GitHub Releases 获取版本信息。
