# 用户效果（SkSL 着色器）

掠影候选窗口支持使用 Skia 专用着色语言（SkSL）进行高级渲染装饰。用户可在面板底层、候选高亮项与右键菜单区域注入自定义着色器代码。若仅需定制静态色彩，推荐直接使用声明式的 [skin.toml](skin.md)。

## 效果槽位与文件结构

在图形设置中开启「候选 → 用户效果」并点击「目录」，即可打开 `%APPDATA%\lueying\effects`。输入法在该目录下提供三个着色器槽位文件：

| 槽位文件名 | 渲染目标区域 | 说明 |
|---|---|---|
| `background.sksl` | 候选窗主体面板背景 | 覆盖候选窗口主面板底衬 |
| `highlight.sksl` | 当前选中候选条目块 | 仅在被选中的候选条目区域渲染 |
| `menu.sksl` | 候选词右键上下文菜单 | 候选右键菜单的背景衬底 |

文件保存后系统在 1 秒内热重载生效，无须重启服务。单槽位语法或编译错误仅停用自身，其余槽位正常运行。

## 着色器契约与 Uniform 规范

每个 `.sksl` 文件必须实现标准的 `main` 入口函数，并返回**预乘 Alpha（Premultiplied Alpha）**颜色值：

```glsl
// 可选：声明契约版本
// effect-api: 1

uniform float2 u_size;   // 当前槽位渲染区域的逻辑宽高（逻辑像素）
uniform float  u_time;   // 动画时钟（单位：秒；系统开启“减少动态效果”时冻结为 0）
uniform float  u_anim;   // 状态过渡进度（0.0 ~ 1.0，静止稳态为 1.0）
uniform float4 u_accent; // 当前主题强调色（归一化 RGB，0.0 ~ 1.0）

half4 main(float2 p) {
    // p 为当前槽位区域内的逻辑坐标，原点位于左上角
    float a = 0.5 * u_anim;
    return half4(u_accent.rgb * a, a); // 必须返回预乘 Alpha 色值
}
```

### 关键约束

- **坐标系统**：输入坐标 `p` 与尺寸 `u_size` 为逻辑像素（DPI 无关），便于编写自适应布局着色器。
- **按需声明**：只需在代码中声明实际使用的 Uniform，未声明的变量由管线自动忽略。
- **文字层绝对保护**：用户着色器仅作用于装饰衬底层，拼音、汉字、数字索引与注释均由核心引擎在上层按高可读性字色独立绘制。

## 可读性与性能保障机制

为了保证文字可读性与打字跟手度，渲染管线内嵌以下保护机制：

1. **对比度保护遮罩**：引擎在上层动态叠加一层对比度底色遮罩，确保文字与背景始终满足 WCAG 标准（正文对比度 ≥ 4.5:1，辅助信息 ≥ 3:1）。
2. **首帧素色降级**：输入组合初次激活的第一帧使用纯色绘制，保证候选词瞬间呈现无视觉延迟。
3. **性能降级熔断**：着色器单帧渲染耗时若连续 2 帧超过 4ms，管线将自动临时挂起该着色器，并在 2 秒后尝试安全恢复。
4. **系统无障碍联动**：
   - 系统开启「高对比度」时，全局着色器被强制关闭。
   - 系统开启「减少动态效果」时，`u_time` 恒定为 0.0，动效冻结在初始稳态。

## 调试与排错

- 着色器加载状态与 SkSL 编译警告/错误会实时写入 `%LOCALAPPDATA%\lueying\logs\server.log`。
- 调试期间可结合日志即时定位着色器语法错误或未识别符号。
