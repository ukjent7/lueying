# 用户效果

候选窗的外观可以自己写一段 SkSL 效果:面板底、选中块、右键菜单底各一个槽位,效果只画装饰层,拼音、候选、序号、注音永远由输入法自己画。只想换颜色不想要动效的话,声明式的 [skin.toml](skin.md) 更简单,效果是它之上的高级层。

## 怎么用

设置里打开「候选 → 用户效果」,点「目录」会打开 `%APPDATA%\lueying\effects`,并在里面放三个模板:

| 文件 | 画在哪 |
|---|---|
| `background.sksl` | 候选窗面板底 |
| `highlight.sksl` | 选中候选的那一块 |
| `menu.sksl` | 右键菜单的底 |

改完存盘,一秒内生效,不用重启输入法。某个文件写坏了只废掉自己那一个槽位,另外两个照常;错误写在服务日志里。

不想用了就把「用户效果」开关关掉,或把三个文件删掉。

## 契约

每个文件是一段 SkSL,只需要一个 `main`:

```glsl
uniform float2 u_size;   // 本槽位区域的逻辑尺寸(设计像素)
uniform float  u_time;   // 动画时钟(秒);「减少动态效果」时冻结为 0
uniform float  u_anim;   // 入场/翻页进度 0..1,静止为 1
uniform float4 u_accent; // 主题色 0..1 RGB

half4 main(float2 p) {
    // p 是本槽位区域内的逻辑坐标,左上角为原点。
    float a = 0.6 * u_anim;
    return half4(u_accent.rgb * a, a);   // 预乘 alpha
}
```

要点:

- **返回预乘 alpha 颜色**:色值已经乘过透明度,直接叠在面板底色上。
- **坐标是逻辑单位**:设计像素,不是物理像素;`u_size` 是这一块自己的尺寸,面板底就是整块面板,选中块就是选中的那一行。
- **只声明你要用的 uniform**:引擎按名字打包,没声明的 uniform 保持 0。
- **可以声明契约版本**:文件头写 `// effect-api: 1`,版本比输入法新就拒绝加载,不会按老语义硬跑。
- **文字层碰不到**:效果没有文本输入,拼音与候选由引擎按主题令牌绘制。

## 输入法的克制

效果之上压着一层引擎自己算出来的遮罩:底色按不透明度压在效果上,不透明度由主题的底色与文字颜色解出来,保证效果再花,候选文字与序号的对比度也有下限(正文 4.5:1,次要文字 3:1)。遮罩按当前主题算,一般在 0.8 以上,也就是效果最终只改动面板底色的一两成:底色会带上你的颜色调子,但压不到抢眼。想让底色更实一点,把自己效果里的 alpha 调到 1 就行;再往上引擎不放行,文字可读性优先。

另外几条:

- 每次组合的第一帧走素色,候选一出现就能读。
- 单帧效果太慢(连续两帧超过 4ms)就先摘掉效果,两秒后再试。
- 系统开启高对比度时,用户效果整个关掉,配色交给系统。
- 系统开启「减少动态效果」时,`u_time` 冻结为 0,动画停在第一帧。

## 调试

- 服务日志里会写「Skia 用户效果已加载:面板底」这样的行,以及编译错误原文。
- 效果在 Skia 候选窗上生效。
