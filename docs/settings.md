# 设置

## 设置窗

从开始菜单选「掠影设置」，或从语言栏菜单打开。修改后立即生效，无需重启服务。

- **输入**：输入方案、五笔辅助码、中文标点、Shift 单击切换、繁体输出、下一词联想。模糊音始终开启,没有开关。
- **候选**：每页数量、横排或竖排、字号、主题色、弹性动效、停顿后换首选。
- **扩展**：运行期扩展的启用、同意与设置。
- **词库**：自定义短语与标点、按应用配置、备份与还原、词库导入。
- **关于**：版本、更新渠道与检查、导出诊断信息。

## config.toml

路径为 `%APPDATA%\lueying\config.toml`，TOML 格式。未知键会被忽略并记录警告；单个值不合法只影响该项。

| 键 | 取值 | 说明 |
|---|---|---|
| `scheme` | `full`、`xiaohe`、`ziranma`、`mspy`、`sogou` | 输入方案；`quanpin`、`flypy`、`zrm`、`microsoft` 为别名 |
| `aux_code` | 布尔 | 五笔辅助码，拼音后按 `` ` `` 输入 |
| `predict` | 布尔 | 下一词联想 |
| `chinese_punct` | 布尔 | 中文全角标点 |
| `shift_toggle` | 布尔 | 单击 Shift 切换中英文 |
| `traditional` | 布尔 | 繁体输出 |
| `traditional_region` | `general`、`tw`、`hk` | 繁体字形区域 |
| `page_size` | 整数 | 每页候选数 |
| `ui_layout` | `horizontal`、`vertical` | 候选排列 |
| `ui_font` | `small`、`standard`、`large` | 候选字号 |
| `ui_accent` | 预设下标或颜色名 | 主题色；高对比度主题忽略 |
| `effects` | 布尔 | 弹性动效；关闭则直接呈现终态 |
| `settled_promote` | 布尔 | 停顿后允许 25M 模型换首选；关闭时首选只随按键变化 |
| `bindings` | 表：组合键 = 完整命令 id | 扩展命令的全局热键 |
| `triggers` | 表：触发词 = 完整命令 id | 候选中的动作触发词，整串匹配才出现 |
| `ocr_engine` | 字符串 | 截图识别引擎；模型缺失时明确报错 |
| `extensions` | 扩展 id 数组 | 启用的运行期扩展，按顺序组合 |
| `allow_all_extension_network` | 布尔 | 跳过扩展的域名白名单，不推荐 |
| `update_channel` | `stable`、`beta` | 更新渠道 |

扩展自己的设置写在 `[ext.<扩展 id>]` 下，由该扩展的清单声明。

## 词库文件

这些文件可以在设置窗的「词库」页内编辑，也可以直接用文本编辑器修改。

- **`phrases.txt`**：自定义短语，每行 `短语<TAB>编码[<TAB>权重]`。
- **`punct.txt`**：自定义标点，每行 `键=输出`，输出最多 16 个字符。
- **`apps.toml`**：按应用覆盖。节名是宿主进程的 exe 文件名（小写），可设 `punct`（标点）与 `learning`（自学习）。未设置的项沿用全局配置。

```toml
[notepad.exe]
punct = false
learning = false
```

## 备份与词库导入

- **备份**：「词库 → 配置备份」把配置、短语、标点、按应用配置与用户词库导出为一个文件；导入时逐块恢复，并立即重载。
- **词库导入**：「词库 → 用户词库 → 导入」合并第三方词表，不清空已有词。支持三种行格式：
  - `词<TAB>拼音<TAB>权重`（搜狗、QQ、Rime 等导出的文本词库）
  - 原生导出的 `键<TAB>词<TAB>频次<TAB>时间戳`
  - 每行一个汉字词，读音从内置词典反查，查不到的行跳过
- 编码支持 UTF-8（可带 BOM）、UTF-16 与 GB18030。用户词库最多 2 万条。
