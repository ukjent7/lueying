# 自定义短语

自定义短语是掠影内置的编译期候选模块扩展。当输入编码命中用户定义的简写或全拼时，短语将作为高优先级候选置顶呈现，上屏后不会污染常规自学习词库。

## 文件位置与编辑

短语存储于 `%APPDATA%\lueying\phrases.txt`：
- 初次运行自动生成带有格式说明的示例文件。
- 可在图形设置页「词库 → 自定义短语 → 编辑」中直接使用内置文本框编辑。
- 保存文件后，在设置页点击「保存」或执行 `lueying ext reload` 即可热加载生效。

## 语法格式

采用纯文本存储，每行一条记录，字段之间使用 **Tab 制表符（`\t`）** 分隔：

```text
短语<TAB>编码[<TAB>权重]
```

### 示例

```text
你好	ni'hao	100
我的邮箱	wo'de'you'xiang	50
快速回复	kshf
```

### 格式规则

- 以 `#` 或 `;` 开头的行为注释行，将被自动忽略。
- **编码格式**：支持完整全拼（如 `ni'hao`）与简拼（如 `kshf`）。包含隔音符 `'` 的全拼编码将自动提取各音节首字母生成简拼索引。
- **权重参数**：可选数值，整数越大候选排序越靠前（默认权重为 1）。
- **容错解析**：单行语法错误将被安全跳过并记录告警，不影响其余条目正常加载。

## 匹配逻辑与边界

1. **多方案自适应**：双拼模式下用户击键先在引擎层展开为规范全拼，因此使用小鹤双拼打出 `nihc` 同样能精准匹配 `ni'hao` 的自定义短语。
2. **完整覆盖原则**：自定义短语仅匹配当前组合缓冲区的完整输入串，不截断作为前缀匹配。
3. **隔离边界**：短语上屏为固定文本，不触发词级转移学习、自动造词或负分惩罚。
4. **辅助码屏蔽**：当用户输入五笔辅助码时，自动屏蔽自定义短语，优先满足字形精准过滤需求。

## 源码实现参考

- `crates/features/src/phrases.rs`：短语解析、索引构建与候选注入。
- `crates/server/src/imp.rs`：短语文件加载与生命周期管理。
