# 自定义短语

自定义短语是候选模块扩展:编码命中时把短语插到候选最前,固定上屏,不写用户词库。

## 文件

`%APPDATA%\lueying\phrases.txt`。首次启动会写一份带注释的模板;设置页「词库 → 自定义短语 → 编辑」会打开它。

保存后在设置页点「保存」,或重启输入法,常驻服务会重新读取。

## 格式

每行一条,字段用 Tab 分隔:

```text
短语<TAB>编码[<TAB>权重]
```

示例:

```text
你好	ni'hao	100
我的邮箱	wo'de'you'xiang	50
```

- `#` 或 `;` 开头的行是注释。
- 编码支持全拼与带隔音符的简拼。`ni'hao` 的简拼是 `nh`;没有隔音符的编码只按完整串匹配。
- 权重越大越靠前,默认 1。
- 坏行跳过,不影响其他短语。

## 匹配

- 全拼:输入规范化后与编码完全一致。
- 简拼:编码按 `'` 分音节,各音节首字母与输入一致。
- 双拼:先展开成规范全拼再匹配,所以 `nihc`(小鹤)也能命中 `ni'hao`。
- 辅助码组合不插入短语;短语没有字形依据。

## 边界

- 短语固定上屏,不参与自动造词、词级转移或负分学习。
- 短语候选覆盖整个当前组合;输入还有剩余拼音时不会只吃前缀。
- 文件没有热监听;改完需要保存设置或重启。

## 实现位置

- `crates/features/src/phrases.rs`:解析、匹配、候选注入。
- `crates/server/src/imp.rs`:文件路径、首次模板、启动加载。
- `crates/server/src/settings_main.rs`:编辑入口。
