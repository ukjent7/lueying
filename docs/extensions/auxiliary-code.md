# 辅助码

辅助码是输入方案扩展:拼音打完后按 `` ` ``,再打 1–2 位字形码,只保留字形相符的候选。当前内置五笔单字码表。

## 开启

设置页「输入 → 辅助码」打开,或写配置:

```ini
aux_code=on
```

## 用法

先正常打拼音,再按 `` ` ``,然后打 1–2 位五笔码:

```text
shi`j
```

`shi` 的候选里有 是、时、十、世、市、试、适、释。五笔码:

| 字 | 五笔前缀 |
|---|---|
| 是 | `j` |
| 时 | `jf` |
| 十 | `fg` |
| 世 | `an` |
| 市 | `ymh` |
| 试 | `yaa` |

所以 `shi`j` 只留 是、时(以及包含这些字的词)。按空格上屏,辅码一起被吃掉。

## 规则

- 辅码只筛覆盖整个基础输入的候选;前缀候选不参与,避免上屏后把辅码留在组合里。
- 单字按「任一码以辅码开头」匹配。
- 词组两位辅码接受两种读法:任一字命中两位;或前一个字命中首位、后一个字命中次位。
- 辅码没有命中时退回完整候选,不会让输入卡死。
- 学习键仍是基础拼音,辅码不写进用户词库。
- 双拼与辅助码可以叠加;`;` 韵母和 `` ` `` 分隔符互不冲突。

## 码表

内置表来自 rime-frost 五笔编码,按《通用规范汉字表》8105 字裁剪,只保留 1–2 位前缀,每字最多三个码。文件在 `crates/features/data/wubi.txt`,随二进制编译。

接入其他字形方案时实现 `lueying_ext::CandidateFilter` 或 `lueying_features::AuxLookup`,再构造 `AuxScheme`;当前宿主只启用内置五笔表。

## 边界

- 辅码长度最多 2 位;多余的字母被忽略。
- 辅助码组合不插入自定义短语与联想候选。
- 码表是单字级;词组按逐字规则匹配,不做词组专用码。

## 实现位置

- `crates/features/src/aux_code.rs`:码表、匹配、方案包装。
- `crates/engine/src/input.rs`:`` ` `` 进入组合、候选筛选后的区间扩展。
- `crates/features/data/wubi.txt`:内置码表。
