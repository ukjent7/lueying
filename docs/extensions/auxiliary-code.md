# 五笔辅助码

辅助码是掠影内置的输入方案扩展。在拼音输入完成后键入反引号 `` ` ``，紧跟 1～2 位五笔字形码，即可根据字形过滤单字候选，大幅减少翻页查找。

## 启用方式

可在图形设置中开启「输入 → 辅助码」，或直接在 `%APPDATA%\lueying\config.toml` 中配置：

```toml
aux_code = true
```

## 输入交互示例

正常键入基础拼音后按 `` ` ``，接着输入五笔前缀码：

```text
shi`j
```

原本 `shi` 的单字候选包含大量同音字（是、时、十、世、市、试、释等）。对应五笔字根：

| 汉字 | 五笔字根编码 | 辅助码匹配（`j`） |
|---|---|---|
| 是 | `j` | **命中** |
| 时 | `jf` | **命中** |
| 十 | `fg` | 未命中 |
| 世 | `an` | 未命中 |
| 市 | `ymh` | 未命中 |

输入 `shi`j` 后候选列表立即过滤并仅保留「是」、「时」（以及以其开头的词组）。按空格直接上屏目标汉字，辅助码随之自动消耗。

## 过滤规则与特性

1. **单字匹配**：只要单字的任一五笔编码以辅助码字符开头，即判定为命中。
2. **两字词组匹配**：支持双码匹配策略——既支持词内任一汉字命中两位编码，也支持首字命中第 1 位且次字命中第 2 位。
3. **安全未命中回退**：若输入的辅助码无任何候选匹配，输入法自动回退保留原始全量候选，避免输入陷入死锁。
4. **学习记录解耦**：自学习词库仅记录基础音节键，辅助码本身不写入用户词库。
5. **双拼兼容**：支持在小鹤、自然码等双拼模式下叠加使用，辅助码分隔符 `` ` `` 与双拼韵母按键完全解耦。

## 内置码表

内置码表源自 rime-frost 五笔编码数据，严格依据《通用规范汉字表》（8105 字）精简裁剪，每字收录最多 3 个有效字根前缀，静态编译集成于二进制中，无运行时磁盘加载负担。

## 源码实现参考

- `crates/features/data/wubi.txt`：精简五笔字形码表源文件。
