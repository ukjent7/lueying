# 下一词联想

下一词联想是掠影内置的编译期候选模块扩展。通过挖掘本地用户词库中的词级转移概率与三词滑动窗口，在用户完成上屏并开始下一段输入时，依据击键前缀自适应推荐后续词。

## 交互流程

1. 用户上屏词语「我」，紧接着上屏「学习」，引擎本地记录词序转移 `我 → 学习`。
2. 后续打字中，用户再次上屏「我」并键入首字母 `x`。
3. 联想模块在「我」的转移候选集合中检索到「学习」（拼音 `xue'xi` 以 `x` 开头），并作为联想词插入候选区。
4. 联想候选带有专属「联想」提示标，紧随首选词之后（最多展示 3 条），避免过度占据首屏。

## 配置开关

可在图形设置中控制「候选 → 下一词联想」，或在 `%APPDATA%\lueying\config.toml` 中配置：

```toml
predict = true  # 默认为 true，设为 false 即可关闭
```

关闭该特性仅停止联想候选的预测注入，已积累的本地词序转移概率不受影响，重新开启后立即可用。

## 匹配逻辑与隐私安全

- **拼音前缀全匹配**：无论是完整拼音（`xue`）还是简拼（`xx`），均能精准命中所学词汇。
- **100% 本地自学习**：无预置云端大模型语料，绝不上报用户上下文。联想建议完全由用户个人在当前机器上的真实写作习惯自演进生成。
- **遗忘同步**：在候选列表中对某联想词按下 `Shift + Delete` 执行遗忘时，该词的转移关系与联想索引同步被彻底清除。
- **辅助码抑制**：进入五笔辅助码过滤模式时，自动停用联想候选，确保字形过滤的纯粹性。

## 源码实现参考

- `crates/features/src/predict.rs`：联想候选匹配与插入逻辑。
- `crates/engine/src/user_learn.rs`：词转移概率模型、转移检索与拼音映射。
- `crates/engine/src/input.rs`：上屏上下文状态机维护。
