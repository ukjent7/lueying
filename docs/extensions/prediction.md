# 下一词联想

下一词联想是候选模块扩展:用本机用户词库里的词级转移与三词窗口,在下一段输入命中某个已学词的拼音前缀时,把它作为「联想」候选插入。

## 行为

1. 用户上屏「我」,再上屏「学习」,引擎记录词序 `我 → 学习`。
2. 下一次上屏「我」后,输入 `x`。
3. 联想模块从 `我` 的后续词里取出「学习」,发现 `xue'xi` 以 `x` 开头,插入候选「学习」。
4. 选中后按完整学习键 `xue'xi` 记录,和正常输入一致。

候选位置在首选之后,最多 3 条,避免把首页灌满。提示文字为「联想」。

## 开关

设置页「下一词联想」默认开启;也可以编辑 `%APPDATA%\lueying\config.ini`:

```ini
predict=false
```

开关只影响后续候选,已经形成的词序保留;重新开启后立即恢复。

## 匹配

- 全拼按字母前缀:`x`、`xu`、`xue` 都能命中 `xue'xi`。
- 简拼按各音节首字母:`xx` 命中 `xue'xi`。
- 只在上一词存在已学转移时触发;三词窗口作为词对为空时的补充。
- 辅助码组合不插入联想。

## 隐私与冷启动

没有云端请求,没有预置语料。第一次接某个词后,下一次就能命中;换机器或清空词库后需要重新形成词序。这是刻意的取舍:联想只反映本机写作习惯。

## 边界

- 联想词必须已经在用户词库里学过,并且有拼音键。
- 只取上一词或前两词的后续,不做整句生成。
- 词条被 Shift+Delete 忘掉后,转移与联想键一起清理。

## 实现位置

- `crates/features/src/predict.rs`:候选注入与拼音前缀匹配。
- `crates/engine/src/user_learn.rs`:`predict_next`、`predict_after`、`key_for_word`。
- `crates/engine/src/input.rs`:把上一词、前两词和用户词库放进 `CandidateContext`。
