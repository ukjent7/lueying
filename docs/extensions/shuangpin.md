# 双拼输入方案

双拼作为编译期输入方案（`Scheme`）接入掠影引擎。输入时两键即可对应一个完整汉语音节，引擎在边界处将其展开为规范全拼后送入词图解码，全量共享主词典、语言模型、纠错逻辑与用户自学习词库。

## 内置支持方案

| 标识符 | 方案名称 | 输入示例（“你好”） | 声母映射规则 |
|---|---|---|---|
| `full` | 全拼（默认） | `nihao` | 标准拼音键位 |
| `xiaohe` | 小鹤双拼 | `nihc` | `v=zh`、`i=ch`、`u=sh` |
| `ziranma` | 自然码 | `nihk` | `k=ao` 等标准映射 |
| `mspy` | 微软双拼 | `nihk` | `;=ing` |
| `sogou` | 搜狗双拼 | `nihk` | `;=ing` |

### 启用方式

在图形设置中心「输入 → 输入方案」中选择，或直接编辑 `%APPDATA%\lueying\config.toml`：

```toml
scheme = "xiaohe"
```

修改后即刻生效，无需重启输入法。

## 交互与编辑行为

- **组合缓冲区映射**：组合区显示用户实际敲击的双拼键；内联高亮、候选窗口与上屏文本均为汉字。
- **逐键与逐音节回删**：
  - `Backspace`：回退单个双拼按键字符。
  - `Ctrl + Backspace`：根据映射区间回退完整的一个音节（即对应双拼的两键）。
- **学习键归一化**：用户词库自学习键统一转换为标准全拼（如 `ni'hao`）。无论后续切换至何种双拼方案或全拼，已记录的用户词条均可正常召回。
- **标点键复用**：微软与搜狗双拼中的分号 `;` 仅在拼音组合中作为 `ing` 韵母，空闲状态下依旧作为标准英文分号输出。
- **隔音符处理**：手动输入单引号 `'` 可主动切断双拼配对起点，便于混合简拼输入。

- `crates/engine/src/input.rs`：输入流水线展开与学习键归一化处理。
