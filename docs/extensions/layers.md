# 扩展分层与权限模型

掠影采用层次化的扩展架构模型。核心引擎不固化具体业务，仅对外暴露安全、可审计的平台原语；不同形态的扩展按照信任边界在专属层级中隔离运行。

## 分层架构矩阵

| 层级 | 运行载体 | 典型应用 | 执行位置 | 隔离与调度机制 |
|---|---|---|---|---|
| **原生内置** | 编译期 Rust | 双拼方案、五笔辅助码、自定义短语 | 常驻服务主线程 | 极高执行效率，按键热路径微秒级响应 |
| **脚本层** | QuickJS 沙箱 | 截图 OCR、外观着色、命令宿主 | 独立扩展工作线程 | 指令预算中断、8ms 单步时限、连续故障熔断 |
| **旁路进程** | 独立外部进程 | 本地大型神经模型、复杂计算 | 独立 Windows 进程 | Job Object 限制，命名管道异步 IPC 通信 |
| **数据层** | 纯文本与映射表 | `phrases.txt`、`punct.txt`、`skin.toml` | 宿主安全解析 | 纯声明式解析，无代码执行风险 |

## 架构原则与信任边界

1. **零空闲成本**：未被激活的扩展不分配独立线程与运行时内存。
2. **热路径零阻塞**：常规打字热路径仅执行声明了触发词的匹配树，匹配时间严格控制在 1ms 内；等待外部异步服务期间不计入脚本步进预算。
3. **平台安全原语**：核心仅提供受控的原语服务：`capture`（截屏）、`ocr`（离线识别）、`clipboard`（剪贴板）、`panel`（弹窗面板）、`output`（文字注入）、`hotkey`（全局热键）、`net`（受限网络代理）、`store`（私有存储）、`notify`（系统通知）。
4. **隐私场景强制挂起**：在系统密码框、私密字段及安全桌面下，扩展层整体自动熔断停用，所有外联、热键与内容提取均被系统拒绝。

## 清单规范（API 2）

扩展必须在包根目录下提供 `manifest.json`：

```json
{
  "id": "shot-ocr",
  "name": "截图 OCR",
  "version": "0.1.0",
  "api": 2,
  "main": "index.js",
  "activate": {
    "triggers": ["ocr"],
    "hotkeys": ["Ctrl+Alt+O"],
    "commands": [
      { "id": "run", "title": "截图并识别文字", "when": "any" }
    ]
  },
  "needs": ["capture", "ocr", "output", "notify"],
  "capabilities": ["screen-capture", "ocr"]
}
```

### 字段说明

- `api`：清单版本号，现代脚本扩展统一采用 `2`。
- `activate.triggers`：输入串完全匹配的触发词，用于调出动作候选。
- `activate.hotkeys`：建议的快捷键绑定（实际绑定关系受用户 `config.toml` 控制）。
- `activate.commands`：命令声明，完整全局标识为 `<扩展 id>.<命令 id>`。
- `needs`：声明需要使用的宿主服务原语。
- `capabilities`：向用户申请的权限集合。

### 权限模型体系

| 权限标识 | 权限说明 | 敏感级别 |
|---|---|---|
| `screen-capture` | 捕获屏幕特定区域位图 | 高敏感 |
| `clipboard` | 读取或写入系统剪贴板纯文本 | 高敏感 |
| `candidate-text` | 获取候选词文字与左邻上下文 | 高敏感 |
| `ocr` | 调用离线 OCR 识别引擎提取文本 | 普通 |
| `network` | 经代理访问网络（必须在清单中声明域名白名单） | 受控外联 |

> [!CAUTION]
> 扩展若同时申请「读取用户内容」（如剪贴板/候选文字）与「网络外联」权限，设置页将触发醒目的高风险安全警告。

## 授权与审计机制

- **哈希指纹校验**：扩展在设置页首次启用时，系统根据清单及入口脚本生成 SHA-256 内容指纹并记录于 `%APPDATA%\lueying\extensions\consent.json`。脚本内容变动后新版本自动挂起，直到用户在设置中再次确认。
- **审计日志追踪**：所有敏感原语调用实时写入 `%LOCALAPPDATA%\lueying\logs\ext-audit.log`，记录调用时间、扩展 ID、调用的服务方法与授权结果，日志绝不保存用户正文内容。

## 沙箱资源约束与熔断

| 资源项 | 限额标准 | 超限处理机制 |
|---|---|---|
| 运行时内存 | 8 MiB | QuickJS 分配器抛出 OOM，立即中止当前任务 |
| 调用栈深度 | 256 KiB | 递归深度超限捕获 |
| 初始化耗时 | ≤ 100 ms | 超时强制终止初始化，扩展置为加载失败 |
| 单步执行耗时 | ≤ 8 ms | QuickJS 中断处理器打断，任务计入一次超时 |
| 命令空闲卸载 | 30 秒 | 无活动事件时自动释放 JS 运行时以回收内存 |
| 容错熔断门限 | 连续 3 次失败 | 自动将该扩展标记为 `disabled`，防止持续扰动 |
